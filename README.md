# E-Commerce Sales Analysis Dashboard

This is my E-Commerce Sales Analysis project made in **Microsoft Excel**.

I created this dashboard to understand sales and order data and find some useful patterns from it.

## What I Analyzed

- Total Order Amount
- Total Number of Orders
- Average Order Amount
- Delivered Orders
- Category-wise Order Amount
- Top 5 States by Order Amount
- Order Status
- Mobile App vs Website Orders
- Month-wise Order Amount

## Filters Used

The dashboard has slicers for:

- Channel
- Month
- Category
- Payment Mode
- Order Status

## Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Excel Formulas

## Some Key Numbers

- **Total Order Amount:** ₹1,34,37,721.62
- **Total Orders:** 1,100
- **Average Order Amount:** ₹12,216.11
- **Delivered Orders:** 554

## Insights

- Most of the orders are coming from the **Mobile App (75%)** compared to the Website (25%).
- **Fashion** has the highest order amount among the categories.
- **Maharashtra** has the highest order amount among the top 5 states shown in the dashboard.
- Out of 1,100 orders, **554 orders were delivered**.
- The order amount changes from month to month, with some months performing better than others.
- Return and cancellation numbers can be checked to find areas where the business can improve.

## Conclusion

This project helped me practice **Excel, Pivot Tables, Charts, Slicers, and basic sales analysis** by working with e-commerce data.
